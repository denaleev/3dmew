# Магазин 3D-печати с конструктором карточек

Интернет-магазин изделий, напечатанных на 3D-принтере:

* **`/`** — витрина для покупателей: каталог, корзина, оформление заказа, заявка «напечатать свою идею» с картинками и 3D-файлами, страница отслеживания заказа.
* **`/builder`** — конструктор карточек (как раньше) + **калькулятор цены** + кнопка «🛒 В магазин», которая публикует карточку на витрине.
* **`/admin`** — управление: заказы и их история, очередь печати, заявки на печать, товары, статистика, настройки.

Аккаунты, карточки, товары, заказы, заявки с файлами и настройки хранятся в PostgreSQL.

## Что внутри

| Папка / файл | Что это |
|---|---|
| `static/shop.html` | витрина магазина (`/`) |
| `static/admin.html` | управление магазином (`/admin`) |
| `static/index.html` | конструктор карточек с калькулятором цены (`/builder`) |
| `static/ai/` | нейросети, которые работают в браузере: удаление фона (U²-Net), чёткость ×4 (Real-ESRGAN), глубина для 3D-поворота (Depth Anything V2), движок ONNX Runtime |
| `models/` | нейросеть распознавания предмета на сервере (CLIP ViT-B/32) и 64 вида поделок |
| `app/` | сервер на FastAPI: аккаунты, вход через соцсети, хранение, ИИ-тексты; `shop.py` — витрина, заказы, заявки; `admin.py` — управление и статистика; `pricing.py` — формула цены |
| `migrations/` | миграции базы (Alembic) |
| `docker-compose.yml` | PostgreSQL 16 в Docker |
| `scripts/install_debian.sh` | установка «под ключ» на чистый Debian 12 |
| `scripts/postgres_docker.sh` | только Docker + PostgreSQL |
| `scripts/backup_db.sh` | резервная копия базы |
| `deploy/` | служба systemd и сайт nginx |
| `tests/` | автотесты API |

### Как хранятся аккаунты

* Пароли хранятся только как хэш **argon2id**. Сам пароль нигде не сохраняется.
* Сессии входа: в cookie лежит случайный токен, в базе только его SHA-256.
* Для входа через Google, Яндекс, Mail.ru и VK в базе лежит только SHA-256 от номера пользователя у этого сервиса. Почта и токены соцсетей не сохраняются.
* Каждый пользователь видит только свои карточки, черновики и фото: сервер проверяет владельца при каждом запросе.

### Где работают нейросети

* **В браузере**, на компьютере или телефоне пользователя:
  * удаление фона;
  * чёткость;
  * 3D-объём (файлы `static/ai/*`, браузер скачивает их один раз и кэширует на 30 дней).
* **На сервере:**
  * распознавание предмета (CLIP, `models/clip_visual.onnx`);
  * тексты от Claude, если в `.env` указан `ANTHROPIC_API_KEY`.
* **Без ключа Claude:** сервер узнаёт предмет («гироскоп-антистресс», «фигурка котика», «ваза»…), а простой текст для ребёнка собирается по шаблону.

## Требования к серверу

* Debian 12 (подойдёт и Ubuntu 22.04/24.04).
* 2 ядра, **2 ГБ памяти** (лучше 4 ГБ), 20 ГБ диска.
* Доступ root по SSH.
* Домен, который указывает на IP сервера (для HTTPS и входа через соцсети).

## Установка за 5 шагов (Debian 12)

1. Загрузи папку проекта на сервер. Пример с компьютера:
   ```bash
   scp kartochki-server.zip root@IP_СЕРВЕРА:/root/
   ssh root@IP_СЕРВЕРА
   apt-get update && apt-get install -y unzip && unzip kartochki-server.zip && cd server
   ```
2. Запусти установку, подставив свой домен:
   ```bash
   sudo bash scripts/install_debian.sh мой-магазин.ru
   ```
   Скрипт по порядку:
   * ставит пакеты;
   * создаёт `.env` со случайными паролями;
   * поднимает PostgreSQL в Docker;
   * создаёт виртуальное окружение Python;
   * выполняет миграции `alembic upgrade head`;
   * запускает службу `kartochki`;
   * настраивает nginx и бесплатный HTTPS (Let's Encrypt).
3. Открой `https://мой-магазин.ru`: откроется витрина магазина. Конструктор: `https://мой-магазин.ru/builder` (вверху появится строка «🧠 Нейросети готовы»). Затем назначь себя администратором (раздел «Магазин → Администратор»).
4. (По желанию) впиши ключи соцсетей и Claude в `/opt/kartochki/.env` (см. ниже), затем выполни:
   ```bash
   systemctl restart kartochki
   ```
5. Проверь работу:
   ```bash
   curl https://мой-магазин.ru/api/health
   # {"ok":true,"ai":true,"claude":false}
   ```

### Ручная установка (если хочется по шагам)

```bash
cp .env.example .env && nano .env            # пароли, адрес сайта
sudo bash scripts/postgres_docker.sh          # Docker + PostgreSQL 16
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
.venv/bin/alembic upgrade head                # создаёт таблицы
.venv/bin/uvicorn app.main:app --host 127.0.0.1 --port 8000
```

Новая миграция после изменения `app/models.py`:

```bash
.venv/bin/alembic revision --autogenerate -m "что поменял"
.venv/bin/alembic upgrade head
```

Приложение тоже можно запустить в Docker: `docker compose --profile app up -d --build`.

# Магазин

## Администратор

Управлять магазином (публиковать товары, видеть заказы, заявки и статистику) может только администратор.

1. Зарегистрируйся на сайте обычным способом (кнопка «Войти» → «Новый аккаунт»).
2. Сделай аккаунт администратором одним из двух способов:
   * впиши имя аккаунта в `.env`: `ADMIN_LOGINS=denis` (несколько через запятую), затем `systemctl restart kartochki`;
   * или выполни `cd /opt/kartochki && .venv/bin/python -m tools.make_admin denis`.
3. Открой `https://мой-магазин.ru/admin`.

## Как товар попадает в магазин

1. Открой конструктор `/builder` и сделай карточку, как обычно.
2. На шаге «2 Текст» раскрой «🧮 Калькулятор цены»:
   1. Впиши вес и время печати из слайсера.
   2. Нажми «✓ Поставить цену».
   3. Там же выбери «Раздел в магазине» (Вазы, Брелоки…).
3. Нажми «🛒 В магазин» вверху. Карточка сохранится в библиотеку и появится на витрине. Картинкой товара станет готовая карточка.
4. Нужно что-то поменять? Открой карточку из кабинета, исправь и снова нажми «🛒 В магазин»: товар обновится, а не задвоится.

В админке на вкладке «Товары» можно, не открывая конструктор:

* скрыть товар;
* поменять цену;
* указать, сколько готовых штук лежит на складе;
* задать порядок в каталоге.

## Файлы для печати (3MF) у карточки

К любой карточке можно прикрепить файлы, по которым её печатать. Например, 3MF-проект из Bambu Studio / Orca / PrusaSlicer со всеми настройками, STL, OBJ, STEP или G-code.

1. В конструкторе на шаге «2 Текст» раскрой «📎 Файлы для печати».
2. Если нужно, впиши заметку: пластик, слой, сколько штук на столе.
3. Нажми «＋ Прикрепить» или перетащи файл. Если карточка ещё не сохранена, она сама сохранится в библиотеку.

Кто видит файлы:

* **Покупатели** — нет.
* **Ты** — в конструкторе у карточки (⬇️ скачать, 🗑 удалить). В кабинете у такой карточки стоит 📎.
* **Администратор** — прямо в заказе («Админка → Заказы»), под каждым товаром. Пришёл заказ: открыл его, скачал 3MF, отправил на принтер.

Размер одного файла — до `MAX_MODEL_MB` (по умолчанию 150 МБ). nginx пропускает до 160 МБ. В офлайн-версии конструктора файлы хранятся в браузере.

## Как считается цена

Всё считается на **одну штуку**. Если за одну печать на столе помещается несколько штук, вес и время печати делятся на их число.

| Обозначение | Что это | Формула |
|---|---|---|
| g | пластик на 1 шт., г | вес из слайсера / штук за печать |
| t | время печати 1 шт., ч | время печати / штук за печать |
| **М** — пластик | | g × (1 + отходы %) × цена кг / 1000 |
| **Э** — электричество | | мощность кВт × t × тариф ₽/кВт·ч |
| **А** — износ принтера | | t × (цена принтера / ресурс в часах + обслуживание ₽/ч) |
| **П** — печать с учётом брака | | (М + Э + А) / (1 − брак %) |
| **Т** — работа | | (подготовка мин / штук + доработка мин) / 60 × ставка ₽/ч |
| **С** — себестоимость | | П + Т + упаковка + доп. расходы |
| Цена | | С × (1 + наценка %) / (1 − налог % − комиссия %), округлённая вверх до «красивой»: …9, …40/…90, …90 |
| Прибыль | | цена × (1 − налог % − комиссия %) − С |

Почему так:

* **Брак** делится, а не прибавляется. Если каждая 14-я печать уходит в мусор (7 %), то пластик и время этой печати оплачивают удачные.
* **Налог и комиссия** тоже делятся. Тогда после их вычета остаётся ровно себестоимость плюс наценка.

Значения по умолчанию можно поменять в «Расходы мастерской» в конструкторе или в «Админка → Настройки»:

| Параметр | По умолчанию |
|---|---|
| Пластик, ₽/кг | PLA 1600, PLA Matte 1800, Silk PLA 2000, PETG 1700, ABS 1600, TPU 2600 |
| Отходы | 5 % |
| Брак | 7 % |
| Принтер | 150 Вт, 70 000 ₽, ресурс 5000 ч, обслуживание 5 ₽/ч |
| Электричество | 6,5 ₽/кВт·ч |
| Труд | 400 ₽/ч, подготовка печати 10 мин |
| Упаковка | 30 ₽ |
| Наценка | 120 % |
| Налог | 6 % |
| Комиссия | 0 % |

**Пример.** Гироскоп из PLA, 45 г, 3 ч 10 мин, 1 шт. за печать:

| Статья | Сумма |
|---|---|
| Пластик | 75,60 ₽ |
| Электричество | 3,09 ₽ |
| Износ принтера | 60,17 ₽ |
| Брак | 10,45 ₽ |
| Работа | 66,67 ₽ |
| Упаковка | 30 ₽ |
| **Себестоимость** | **245,97 ₽** |
| Цена по формуле | 575,68 ₽ |
| **Цена на витрине** | **590 ₽** |
| Прибыль | 308,63 ₽ (≈ 97 ₽ за час работы принтера) |

Та же формула есть в `app/pricing.py` (сервер, заявки в админке) и в конструкторе, поэтому цифры совпадают. Офлайн-версия конструктора хранит свои цифры расходов в браузере.

## Заказы

Покупатель кладёт товары в корзину и оформляет заказ. Входить в аккаунт не обязательно, нужен телефон или почта. После оформления он получает ссылку, по которой видны статус и история заказа. Если покупатель вошёл в аккаунт, все его заказы собраны в «Мои заказы».

Статусы: **Новый → Подтверждён → Печатается → Готов → Отправлен → Выполнен** (или **Отменён**).

Каждое изменение записывается в историю: кто, когда и что сделал.

* «Сообщение покупателю» видно на странице заказа.
* «Заметка для себя» (🔒) покупателю не показывается.

Новый заказ покупатель может отменить сам. Заказ в работе отменяет только администратор.

Если у товара указан запас «на складе», заказ сначала берёт готовые штуки. Печатать нужно только недостающие. При отмене запас возвращается.

Выгрузка всех заказов в Excel: кнопка «⬇️ Excel (CSV)» в админке.

**Заказ не с сайта** (MAX, телефон, ярмарка): «Админка → Заказы → ＋ Новый заказ». Укажите, откуда пришёл, покупателя, статус, оплату и позиции: товар из магазина (с цветом; пустая цена = цена магазина с учётом цвета) или «Свой товар» с названием и ценой. Галочка «Списать со склада» берёт готовые штуки. Такой заказ попадает в общий список, очередь печати и статистику; покупателю ничего не отправляется.

**Очередь печати** («Админка → Очередь печати») показывает, в каком порядке печатать:

1. то, что уже печатается;
2. заказы со сроком, по сроку;
3. остальные по очереди.

Для каждого заказа видны часы печати нарастающим итогом и дата, когда он будет готов при заданном числе принтеров и часов работы в сутки. Если не успеваем к сроку, строка помечена ⚠️.

## Заявки «напечатать свою идею»

1. Покупатель описывает идею и прикладывает до 10 файлов: фото, картинки, STL, 3MF, OBJ, STEP, PDF, ZIP, всего до `MAX_UPLOAD_MB`.
2. В «Админка → Заявки» ты смотришь картинки и скачиваешь 3D-файлы.
3. Там же считаешь цену встроенным калькулятором и нажимаешь «📨 Отправить цену клиенту».
4. Покупатель видит цену по своей ссылке. Если он нажимает «Согласен», заявка сама становится заказом и попадает в очередь печати.

Файлы хранятся в базе и доступны только автору заявки (по ссылке или в аккаунте) и администратору.

## Статистика

«Админка → Статистика» показывает данные за 7 дней, 30 дней, 3 месяца, год или всё время.

* **Деньги:** выручка, прибыль и маржа, средний чек, средняя цена штуки, продано штук, расход пластика.
* **Загрузка принтеров:**
  * сколько часов печати в сутки приходит заказов;
  * какая это доля от возможного (принтеров × часов в сутки);
  * сколько часов в очереди и через сколько дней она закончится;
  * прогноз на неделю;
  * сколько принтеров нужно с запасом 20 %.
* **Популярные товары:** штуки, заказы, выручка, прибыль, часы печати, просмотры и конверсия (заказов на 100 просмотров).
* **Графики:** выручка и часы печати по дням, заказы по дням недели, заказы по статусам, расход пластика по видам.

Число принтеров и часов работы в сутки задаются в «Настройках».

Кнопка «♻️ Сбросить статистику» начинает счёт заново: просмотры товаров обнуляются, а выручка, заказы, продажи и порядок «Популярные» считаются только с момента сброса. Сами заказы и заявки не удаляются.

## Продавец, политика конфиденциальности и условия заказа

Внизу каждой страницы магазина есть ссылки на четыре страницы, которые собираются из настроек:

- `#info/terms`: условия заказа, оплаты, доставки и возврата. Там же сказано, что каталог не является публичной офертой (п. 2 ст. 437 ГК РФ) и договор заключается после подтверждения заказа продавцом;
- `#info/privacy`: политика конфиденциальности (152-ФЗ);
- `#info/consent`: отдельный текст согласия на обработку персональных данных;
- `#info/seller`: продавец, ИНН и контакты.

Данные продавца заполняются в **Админке → Настройки → Продавец и юридические страницы**: ФИО, статус (самозанятый или ИП), ИНН, город, срок изготовления. Тексты про оплату, доставку и возврат можно заменить своими, а если поле пустое, показывается стандартный текст. Указывайте данные взрослого продавца.

При заказе и при заявке «своя идея» покупатель ставит две галочки: согласие на обработку данных и согласие с условиями. Без них сервер не примет заказ (ошибка 400), а в истории заказа записывается, что согласие получено.

Тексты — шаблон, а не юридическая консультация. Перед началом продаж покажите их юристу и подайте уведомление об обработке персональных данных на pd.rkn.gov.ru.

## Витрина: группы, фильтры, цвета, фото и видео

- **Группы товаров** — это поле «Раздел в магазине» (категория). На главной они показаны подписями для быстрого перехода. Порядок, названия и видимость задаются в «Админка → 🗂 Категории»: переименование переносит все товары группы, удаление оставляет товары без группы, пустые группы на витрине не видны. Рядом поиск, сортировка и кнопка «⚙️ Фильтры»: только в наличии, цена от и до, материал, цвет.
- **Цвета пластика.** Админка → «🎨 Цвета»: название, цвет (можно два для двухцветных и Silk), материал, примечание и фото катушки или образца. Какие цвета можно выбрать у товара, отмечается в его редактировании. Если цвета у товара не отмечены, доступна вся палитра. В карточке товара первым стоит **стандартный цвет** (тот, что указан в калькуляторе конструктора, поле «Цвет пластика»; можно выбрать из подсказки), за ним 3 самых заказываемых, остальные в списке «Ещё N цветов». Стандартный цвет выбран сразу, «В корзину» с плитки тоже кладёт его. Цвет попадает в заказ. Все цвета с фото видны на странице `#palette`.
- **Цена по цвету.** У цвета можно указать цену пластика за кг. Если у товара указан вес (поле «Вес изделия, г» в редактировании, или вес из калькулятора), цена в этом цвете пересчитывается с той же наценкой, отходами и налогом, что в калькуляторе. Покупатель видит рядом с каждым цветом «+N ₽» или «−N ₽», и итог меняется при выборе. Без цены за кг цвет идёт без доплаты.
- **Доплата за цвет в карточке.** При выборе цвета под ценой пишется «Базовая цена … · цвет: +N ₽ / −N ₽ / без доплаты». Расчёт из калькулятора: меняется только стоимость пластика (цена за кг у цвета во вкладке «🎨 Цвета»). Если у цвета не указана цена за кг, доплаты нет.
- **Несколько цветов.** В карточке товара кнопка «🌈 Несколько цветов»: покупатель отмечает от 2 до 4 цветов. В корзине и заказе такая позиция идёт с ориентировочной ценой (по самому дорогому из выбранных цветов) и пометкой «цену подтвердит мастер», со склада она не списывается. В админке у заказа стоит «🌈 нужна цена»: после расчёта в слайсере впиши цену за штуку (и время печати) и нажми «✓ Подтвердить». Итог заказа пересчитается, а покупатель увидит подтверждённую цену в истории заказа. Цену любой позиции можно поправить карандашом ✏️.
- **Карусель в каталоге.** Если у товара несколько фото или видео, их можно листать прямо в плитке: стрелками на компьютере, свайпом на телефоне.
- **Правка прямо с витрины.** Администратор видит в карточке товара панель: «✏️ Изменить» (название, цена, скидка, группа, наличие, описание, характеристики, цвета, фото и видео), «🙈 Скрыть», «🗑 Удалить», «🎨 В конструкторе», «📣 В MAX». Кнопка «＋ Товар» открывает конструктор карточек, галочка «скрытые» показывает скрытые товары.
- **Наличие.** «В наличии, шт.» задаётся в конструкторе (поле под разделом магазина), в редактировании на витрине или во вкладке «Товары». 0 значит «печатаем под заказ».
- **Фото и видео.** До 20 файлов за раз: JPG/PNG/WEBP или MP4/MOV/WEBM (видео до `MAX_VIDEO_MB`, по умолчанию 100 МБ). Любое фото можно сделать главным ⭐.

## Корзины, избранное, отзывы

- **Личный кабинет.** Кнопка с именем покупателя открывает меню: личный кабинет, мои заказы и заявки, избранное, корзина, настройки и безопасность, выход (у администратора ещё «Управление магазином»). На странице `#account`: сводка (заказы, заявки, избранное, корзина), контакты и адрес для заказов (подставляются при оформлении, галочка «Запомнить контакты» сохраняет их после заказа), смена или установка пароля (другие устройства при этом выходят), «Выйти на всех устройствах», удаление аккаунта (по слову «удалить» и паролю; заказы остаются у магазина без связи с аккаунтом; аккаунт администратора так удалить нельзя).

- **Корзины без заказа** — Админка → «🛒 Корзины»: что покупатели положили в корзину и не оформили. Хранятся только товары и количество под случайным номером (имя видно, если покупатель вошёл в аккаунт). После заказа корзина пропадает из списка.
- **Кнопка «В корзину»** после нажатия превращается в счётчик «− n +» и кнопку 🛒, которая открывает корзину. Минус до нуля убирает товар из корзины.
- **Отложенные** — в той же вкладке «🛒 Корзины» ниже: сколько посетителей добавили товары в избранное, сколько отметок, на какую сумму, таблица по товарам (сколько отложили и сколько из них уже в корзине) и список по посетителям.
- **Удаление заказа** — кнопка «🗑 Удалить заказ» в карточке заказа. Если заказ не выполнен, взятые со склада штуки возвращаются.
- **Избранное** — ♡ на плитке и в карточке товара, страница `#fav`. У гостя хранится в браузере, у вошедшего — в аккаунте.
- **Отзывы** — звёзды, текст и до 3 фото. Каждый отзыв ждёт проверки: Админка → «⭐ Отзывы» (опубликовать, отклонить, удалить). Рейтинг товара считается только по опубликованным.
- **Плитки на витрине** показывают карточку из конструктора, обрезанную снизу, чтобы не было видно плашки с ценой (цена написана под картинкой). В окне товара карточка видна целиком, кнопка ⬇️ во вкладке «Товары» скачивает её с ценой.

## Конструктор: публикация и калькулятор

Главная кнопка конструктора — «🛒 Опубликовать на витрине»: карточка сохраняется в библиотеку и сразу появляется в магазине. Скачать PNG можно маленькой кнопкой рядом. Готовая карточка (например, импортированная) по кнопке «🎨 В конструкторе» открывается как есть, без перерисовки: поля можно править, картинка остаётся прежней, а «✏️ Собрать заново из фото» перерисует её конструктором. В калькуляторе выбирается **тип пластика** (или «＋ Другой пластик…») и отдельно вписывается **цена пластика за кг**, если катушка стоила не так, как в настройках мастерской.

Кнопка «↺ Стандартные параметры» в настройках калькулятора (в конструкторе и в «Админка → Настройки») подставляет исходные цифры. Применяются они после «Сохранить».

## О проекте, footer и обратная связь

- Текст внизу сайта и ссылка на MAX: Админка → Настройки.

Для почты нужен пароль приложения Яндекса: id.yandex.ru → Безопасность → Пароли приложений → «Почта», затем в `.env`: `SMTP_USER=mew.shop@yandex.ru` и `SMTP_PASSWORD=<пароль приложения>`. В настройках ящика должен быть разрешён доступ почтовым программам.

## Бот MAX

Кнопка **«Мы в MAX»** на главной (рядом с «Напечатать свою идею») ведёт по ссылке из «Админка → Настройки → Ссылка для кнопки «Мы в MAX»». Пустое поле — кнопки нет (если в поле «MAX» указана ссылка https://, используется она).

4. Кнопка «📣 В MAX» в карточке товара отправляет в группу фото, название, цену, описание и кнопку «Открыть в магазине».

## Готовые карточки 3DМяу

В `seed/` лежат 16 карточек (4 группы: Котики, Антистресс, Хэллоуин, Для дома). Импорт в библиотеку конструктора и в магазин:

cd /opt/kartochki && .venv/bin/python -m tools.import_cards denis            # сразу на витрине

## Обновление старой установки до магазина

```bash
cd /opt/kartochki
# скопируй новые файлы поверх старых, затем:
.venv/bin/pip install -r requirements.txt
.venv/bin/alembic upgrade head      # добавит таблицы магазина, старые карточки и аккаунты не тронет
systemctl restart kartochki
```

Чтобы прикреплять к карточкам большие 3MF-файлы, подними предел загрузки в nginx: в `/etc/nginx/sites-available/kartochki` поставь `client_max_body_size 160m;` и выполни `systemctl reload nginx`.

Конструктор переехал с `/` на `/builder`; на `/` теперь витрина. Адреса возврата для входа через соцсети не меняются.

## Вход через соцсети

Для каждого сервиса нужно зарегистрировать приложение и указать адрес возврата (redirect URI).

| Сервис | Где создать приложение | Адрес возврата | Что вписать в `.env` |
|---|---|---|---|
| Google | console.cloud.google.com → APIs & Services → Credentials → OAuth client ID (Web application) | `https://ДОМЕН/api/auth/google/callback` | `GOOGLE_CLIENT_ID`, `GOOGLE_CLIENT_SECRET` |
| Яндекс | oauth.yandex.ru → Создать приложение (веб-сервисы), доступ «Логин: имя пользователя» | `https://ДОМЕН/api/auth/yandex/callback` | `YANDEX_CLIENT_ID`, `YANDEX_CLIENT_SECRET` |
| Mail.ru | o2.mail.ru/app → Создать приложение | `https://ДОМЕН/api/auth/mailru/callback` | `MAILRU_CLIENT_ID`, `MAILRU_CLIENT_SECRET` |

# Размещение на SpaceWeb (cp.sweb.ru)

**Обычный «виртуальный хостинг» SpaceWeb для этого проекта не подходит.** Проекту нужны:

* Docker и PostgreSQL;
* постоянно работающий Python-сервер;
* около 1 ГБ памяти под нейросеть.

На виртуальном хостинге нет root-доступа, поэтому нужен **VPS**.

1. **Закажи VPS.**
   1. Войди в cp.sweb.ru и открой раздел **VPS**, нажми «Заказать».
   2. Выбери тариф: не меньше **2 ядер, 2–4 ГБ памяти, 20+ ГБ диска**.
   3. Выбери образ **Debian 12**. Если его нет в списке, подойдёт Ubuntu 22.04/24.04: скрипты работают и там.
   4. После создания в карточке сервера будут IP-адрес и пароль root. Их же пришлют на почту.
2. **Домен.**
   1. Если домен куплен в SpaceWeb, открой «Домены и DNS» и у нужного домена измени A-запись `@` (и `www`, если нужна) на IP твоего VPS.
   2. Если домен у другого регистратора, сделай то же в его DNS-панели.
   3. Подожди от 15 минут до нескольких часов, пока запись обновится. Проверить: `ping мой-магазин.ru` должен показать IP сервера.
3. **Загрузи проект.**
   * Linux/macOS, с компьютера: `scp kartochki-server.zip root@IP:/root/`.
   * Windows: используй WinSCP, FileZilla (протокол SFTP) или `scp` в PowerShell.
   * Можно также открыть веб-консоль VPS в панели SpaceWeb.
4. **Установи.**
   1. Подключись по SSH: `ssh root@IP`.
   2. Выполни:
      ```bash
      apt-get update && apt-get install -y unzip
      unzip kartochki-server.zip && cd server
      bash scripts/install_debian.sh мой-магазин.ru
      ```
5. **Проверь.**
   1. Открой `https://мой-магазин.ru`.
   2. Создай аккаунт, сделай его администратором, открой `/builder`, сделай карточку и нажми «🛒 В магазин».
   3. Если HTTPS не выдался (домен ещё не обновился), позже выполни `certbot --nginx -d мой-магазин.ru`.
6. **Соцсети и Claude.**
   1. Впиши ключи в `/opt/kartochki/.env`, как в разделе выше.
   2. Выполни `systemctl restart kartochki`.
7. **Файрвол** (по желанию):
   ```bash
   apt-get install -y ufw
   ufw allow OpenSSH && ufw allow 'Nginx Full' && ufw enable
   ```
   PostgreSQL наружу не открыт: он слушает только 127.0.0.1.

Названия разделов и тарифов в панели SpaceWeb могут немного отличаться. Если чего-то не нашёл, напиши в поддержку SpaceWeb: «нужен VPS с Debian 12 и root-доступом».

# Размещение на REG.RU

**Обычный хостинг REG.RU (виртуальный хостинг для сайтов на PHP/WordPress) не подходит.** Проекту нужны Docker, PostgreSQL, постоянно работающий Python и около 1 ГБ памяти под нейросеть. Нужен **облачный сервер (VPS)** с root-доступом.

1. **Закажи сервер.**
   1. Войди в личный кабинет reg.ru, открой «Облачные серверы» (Рег.облако) → «Создать сервер».
   2. Образ: **Ubuntu 24.04** или **Debian 12**, без панели управления (ISPmanager не нужен).
   3. Тариф: не меньше **2 ядер, 4 ГБ памяти, 30+ ГБ диска** (2 ГБ хватит впритык).
   4. Создай сервер. IP-адрес и пароль root придут на почту и будут в карточке сервера.
2. **Домен.**
   1. Если домен куплен на reg.ru: «Домены» → нужный домен → «DNS-серверы и управление зоной».
   2. Проверь, что стоят DNS-серверы REG.RU (ns1.reg.ru, ns2.reg.ru).
   3. Добавь A-запись `@` → IP сервера и A-запись `www` → тот же IP.
   4. Подожди от 15 минут до нескольких часов. Проверка: `ping мой-магазин.ru` показывает IP сервера.
3. **Загрузи проект.** С компьютера: `scp kartochki-server.zip root@IP:/root/`. На Windows подойдёт WinSCP или FileZilla (протокол SFTP).
4. **Установи.**
   ```bash
   ssh root@IP
   apt-get update && apt-get install -y unzip
   unzip kartochki-server.zip && cd server
   bash scripts/install_debian.sh мой-магазин.ru
   ```
5. **Назначь администратора.**
   1. Открой `https://мой-магазин.ru` и зарегистрируйся.
   2. На сервере впиши своё имя в `/opt/kartochki/.env` (`ADMIN_LOGINS=имя`).
   3. Выполни `systemctl restart kartochki`.
   4. Админка: `https://мой-магазин.ru/admin`.
6. **Если HTTPS не выдался** (домен ещё не обновился): позже выполни `certbot --nginx -d мой-магазин.ru -d www.мой-магазин.ru`.
7. **Файрвол** (по желанию): `apt-get install -y ufw && ufw allow OpenSSH && ufw allow 'Nginx Full' && ufw enable`.

Названия разделов в кабинете reg.ru могут немного отличаться. Если что-то не нашёл, напиши в поддержку: «нужен облачный VPS с Ubuntu 24.04 и root-доступом».
